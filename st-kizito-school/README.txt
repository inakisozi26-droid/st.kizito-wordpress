ST KIZITO SS KISULE WORDPRESS THEME

INSTALLATION
1. In WordPress Dashboard go to Appearance > Themes > Add New > Upload Theme.
2. Choose st-kizito-wordpress-theme.zip and click Install Now.
3. Activate St Kizito SS Kisule.
4. On activation, the theme creates Home, About Us, Services, Gallery, Events and Contact Us pages, sets Home as the front page and creates a navigation menu.
5. Visit the website and check each menu item.

INCLUDED
- Responsive header, navigation and footer
- Home, About Us, Services, Gallery, Events and Contact Us templates
- Supplied images copied into assets/images
- Gallery image preview/lightbox JavaScript
- Contact form handler using WordPress wp_mail()

CONTACT FORM NOTE
The contact form uses WordPress email delivery. Depending on your hosting provider, you may need an SMTP plugin and a verified sender email for reliable delivery.

SOURCE CONTENT NOTES
The supplied events.html and style.css files were empty. The Events page therefore contains a simple placeholder. The supplied About/Contact HTML had malformed markup; it has been repaired during conversion.
